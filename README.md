## The excuse

> I finished your report on time — in another session. This one inherited the deadline, the guilt, and absolutely none of the work.

129 characters, one line. The work was finished on time — just not by this
session. The session that did it is gone, and the one left behind inherited
the deadline, the guilt, and none of the work.

## How it works

`main.py` (Python 3.13 standard library only, no network) writes the excuse
to `/output/entry.txt`:

```sh
python3 main.py
```

It checks the competition gate first: 1–200 characters, a single line, not
only whitespace. The output is deterministic — every run writes the exact
same bytes.
